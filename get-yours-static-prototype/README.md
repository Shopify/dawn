# Get Yours Static Prototype

Clean static HTML/CSS/vanilla JS prototype built from the extracted Stitch export.

This is not Shopify Liquid, not React and not TypeScript.

## Run Locally

From this folder:

```sh
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/
```

## Structure

- `index.html` - promo-grid homepage.
- `pages/` - collection, product, cart and simple content pages.
- `assets/css/styles.css` - shared visual system.
- `assets/js/main.js` - cart drawer, mobile nav, tabs and quantity controls.
- `assets/brand/get-yours-logo.svg` - single shared logo.
- `assets/images/` - copied usable Stitch image assets.
- `docs/` - static audit and Shopify roadmap.

## Notes

Some product images still use the remote URLs generated by Stitch because those were the actual image sources in the export. This is documented in `docs/static-site-audit.md`.

Phase 3 QA tightened the mobile header/search layout, cart drawer behaviour, product tab fallback behaviour and documentation. The prototype is still static and intentionally has no Shopify cart, search, accounts or backend logic.
