# Cellife footer

The existing Dawn footer now supports the Cellife layout: an editable brand block
and Shop, Company and Support menu columns. Its existing colour scheme and
background are unchanged. Native footer utilities, policies, icon credits and the
separate active first-order signup section are retained.

In the Theme Editor, open **Footer → Cellife brand** to edit the supplied blurb,
tagline, optional logo and logo width. An unset logo uses the store logo. The
three menu blocks have native menu pickers. When no picker is selected, the
existing menu with the same title as the column heading is resolved through
Shopify's linklists; menu handles and destination links are not invented or
hard-coded. Selecting a menu overrides that title fallback.

Footer settings include the Cellife layout switch and editable copyright name.
The layout uses four columns on desktop, a full-width brand area above three
menus on tablet, and a full-width brand area above two menu columns on mobile.

The old public footer was inspected read-only to verify the three menu titles
and links: https://cellifehealthcare.com.au/ . Public HTML did not reveal menu
handles; no backend menus or live theme were changed.
