# Даминфиси — корпоративен уебсайт

Статичен многостраничен сайт (HTML5, CSS3, vanilla JavaScript). Без фреймуърци, без npm и без build стъпка.

## Структура

```
daminfisi-website/
├── index.html              Начало: герой, направления, за нас, защо Даминфиси, проекти, контакти
├── agriculture.html        01 Технологии за земеделие и преработка на продукция
├── energy-transport.html   02 Енергийни решения и хладилен транспорт
├── windows-doors.html      03 PVC и алуминиева дограма
├── 404.html                Страница за грешка (Cloudflare Pages я използва автоматично)
├── style.css
├── script.js
├── _headers                HTTP хедъри и кеширане за Cloudflare Pages
├── robots.txt
└── assets/
    ├── images/             Снимки от корпоративното представяне (WebP, 1600px + 800px)
    └── logo/               Словесен знак (SVG, тъмен и светъл), favicon
```

## Публикуване в Cloudflare Pages

1. Cloudflare Dashboard → Workers & Pages → Create → Pages → **Upload assets**.
2. Качете съдържанието на папката `daminfisi-website/` (или ZIP архива).
3. Build command: *няма*. Output directory: корена на архива.

При свързване с Git репозиторий: Framework preset **None**, build command празно, output directory `daminfisi-website`.

## Формуляр за запитване

Формулярът валидира полетата, но **не изпраща данни, докато не бъде свързан с услуга**. Без настройка потребителят вижда ясно съобщение, че онлайн изпращането още не е активно — сайтът не симулира успешно изпращане.

За активиране задайте адреса на услугата в `index.html`:

```html
<form ... id="inquiry-form" data-endpoint="https://formspree.io/f/XXXXXXX">
```

Скриптът изпраща `POST` с `FormData` и заглавие `Accept: application/json`; всеки отговор 2xx се счита за успех. Подходящи варианти: Formspree, Getform, Basin или собствена Cloudflare Pages Function (`functions/api/inquiry.js`) — тогава `data-endpoint="/api/inquiry"`.

Имена на полетата: `ime`, `kompaniya`, `email`, `telefon`, `napravlenie` (`agri` | `energy` | `windows` | `other`), `saobshtenie`; `_gotcha` е скрито поле срещу спам.

Направлението се попълва автоматично от адреса, напр. `index.html?napravlenie=energy#kontakti` (използва се от бутоните на страниците по направления).

## Съдържание за допълване

Представянето не съдържа следната информация; на сайта тя е отбелязана с пунктирани етикети „за допълване“:

- телефон, имейл и точен адрес (известно е само: Дупница, България) — в контактната секция на `index.html` и във футъра на всички страници;
- снимки и описания на конкретни реализирани обекти;
- технически характеристики на PVC и алуминиевите профилни системи;
- конкретни модели и параметри на хладилния транспорт.

Не са добавяни сертификати, партньори, статистики или исторически данни извън представянето.

## Лого

Представянето използва словесен знак „ДАМИНФИСИ“ (DejaVu Sans Bold, главни букви). Файловете в `assets/logo/` са векторно пресъздаване на този знак. Ако компанията разполага с официален векторен логотип, заменете `daminfisi-logo.svg` (тъмен) и `daminfisi-logo-light.svg` (светъл) с файлове със същите имена.

## След определяне на домейна

- В `<head>` на всяка страница заменете `og:image` с абсолютен адрес (`https://домейн/assets/images/og-image.jpg`) и добавете `<link rel="canonical">` и `og:url`.
- Добавете `sitemap.xml` и ред `Sitemap:` в `robots.txt`.

## Дизайн

- Палитра от представянето: тъмнозелено `#0A251B`, кремаво `#F3F1E9`; акценти по направления — маслинено (земеделие), кехлибарено (енергия), стоманено сиво (дограма).
- Шрифтове: Source Serif 4 (заглавия) и Manrope (текст), Google Fonts с кирилица.
- Анимациите се изключват при `prefers-reduced-motion`.
