## Cancellation Operations

Internal baseline: cancellation is most likely before a supplier order is placed. After supplier commitment, cancellation depends on supplier status and cannot be guaranteed. This remains an operating rule, not a legal conclusion.

| Order stage | Recommended handling | Current status | Required input or confirmation |
| --- | --- | --- | --- |
| Checkout attempted; no confirmed order | Check Shopify order and payment state before suggesting another checkout attempt. | Merchant input required | Adopt or amend the payment-support procedure. |
| Order created; unpaid | Take no supplier action; verify payment state. | Merchant input required | Adopt or amend. |
| Paid and under merchant review | Hold supplier action while the cancellation request is assessed. | Merchant input required | Assign support/fulfilment owner and approval rule. |
| Paid; no CJ order placed | Verify no supplier order exists before deciding; this is normally the most feasible cancellation stage. | Merchant input required | Adopt or amend refund authority. |
| CJ order placed; not processed | Ask supplier whether cancellation is possible before committing to an outcome. | Supplier/provider confirmation required | Confirm CJ cancellation workflow for the actual supplier/order. |
| Supplier processing started | Escalate case by case; give no cancellation promise. | Supplier/provider confirmation required | Confirm supplier process and merchant escalation authority. |
| Supplier shipped | Treat as a delivery/returns matter rather than routine cancellation. | Merchant input required | Adopt or amend returns escalation procedure. |
| Delivered | Route to final approved returns process. | Professional confirmation required | Final process depends on merchant decision and South African legal review. |
